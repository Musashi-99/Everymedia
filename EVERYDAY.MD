# Everymedia --- Homepage Design & Build Specification

## 01. Project Direction

**Design reference:** Premium creative-agency / technology studio
website.

**Primary visual direction** - Editorial + cinematic +
technology-driven. - Use the third reference image as the main
structural inspiration. - Borrow the clean spacing and card discipline
of the second reference. - Use the first reference only for selected
card/grid ideas. - Do **not** make the page look like an architecture,
travel, or sports website. - The finished page should feel like a
high-end creative technology agency.

**Core visual idea**

> Creative × Technology × Data

The homepage should communicate: 1. Creativity 2. Technology 3. Data 4.
Campaigns 5. Digital experiences 6. Human/team capability 7. Premium
execution

# 25. DESIGN PRINCIPLES

### Principle 01 --- Image first

Photography should do most of the emotional work.

### Principle 02 --- Typography second

Large typography should establish hierarchy immediately.

### Principle 03 --- Keep UI quiet

Buttons and navigation should never compete with the work.

### Principle 04 --- Use asymmetry

Avoid making every section a standard three-column grid.

### Principle 05 --- Make every section feel editorial

The page should resemble a premium creative publication as much as a
corporate website.

### Principle 06 --- Real content only

Do not invent awards, clients, statistics, campaigns, people, or company
claims.

### Principle 07 --- Premium through restraint

Use fewer colors, fewer borders, fewer shadows and more whitespace.

------------------------------------------------------------------------

# 26. FINAL VISUAL TARGET

The final homepage should feel like:

**A premium creative agency × technology studio × editorial portfolio.**

The closest structural reference is **Image 3**, while the cleanliness
of **Image 2** and selected card/grid ideas from **Image 1** should

-   Editorial
-   High-end
-   Modern
-   Technology-focused
-   Human
-   Portfolio-driven
-   Spacious
-   Conversion-focused

It should **not** look like: - A generic SaaS website - A template
agency site - An architecture portfolio - A travel website - A corporate
consulting website
